# INNOVATECH — AI & Technology Club Website
### Centre Universitaire d'Illizi (CU Illizi)

Official website for **INNOVATECH**, the Artificial Intelligence, Robotics, and Technology Club at the **Centre Universitaire d'Illizi** (جامعة إليزي), Algeria.

---

## 🌟 Features

- **Futuristic AI Theme**: Designed around the club's brand identity and logo colors (`#0DB59E` Cyber Teal, `#0DF5C4` Neon Glow, Midnight Obsidian).
- **Interactive Neural Network Canvas**: Real-time connected synaptic nodes responding to mouse movement.
- **Dynamic Specialty Rotator**: Real-time typewriter effect cycling through AI, Computer Vision, Robotics, and STEM outreach.
- **Responsive Showcase Gallery**:
  - `9.png` — National Innovation Expo & YOLOv8 Camel Collision Detection AI
  - `3.png` — Autonomous 4WD Arduino Rover Workshop
  - `5.png` — Meta Quest Virtual Reality Demonstration
  - `6.png` — Software Engineering & Embedded AI Lab
  - `2.png` — Smart Recycling & Waste Sorting System
  - `4.png` — STEM Awareness Caravan (*زيارة تحسيسية*)
  - `7.png` — Hands-on Circuit & Robotics Mentorship
- **Flagship AI Research Spotlight**:
  - *Desert AI Camel Detection System*: Deep learning model (YOLOv8) to prevent highway vehicle collisions in the Algerian Sahara.
  - *Smart Reverse Vending Machine (RVM)*: Vision-based plastic bottle recycling with rewards.
- **University Location & Map**: Centre Universitaire d'Illizi (26.52229° N, 8.48378° E) with embedded Google Maps.
- **Social Media Integration**:
  - Instagram: [@innovatech_club](https://www.instagram.com/innovatech_club)
  - Facebook: [Innovatech club](https://www.facebook.com/innovatech_club)
  - TikTok: [@innovatech](https://www.tiktok.com/@innovatech)
- **Interactive Modals**: Fullscreen image lightbox, multi-step "Join Us" recruitment form, and "Contact Us" inquiries.
- **CSS5 & Media Queries**: Responsive across mobile, tablet, and desktop screens.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser, or serve locally with Python:

```bash
python -m http.server 3000
```
Then visit `http://localhost:3000`.
